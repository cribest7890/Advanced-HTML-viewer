Advanced HTML Viewer is a lightweight browser-based HTML project editor and viewer.

It allows you to import entire HTML projects, browse files through a project tree, edit source code with syntax highlighting and autocomplete, and instantly preview changes in real time.

## Features

* 📁 Import complete folders or individual files
* 🌳 File tree navigation with folder support
* ✏️ Built-in code editor powered by CodeMirror
* 🎨 Syntax highlighting for HTML, CSS, and JavaScript
* ⚡ Live preview with automatic refresh
* 🔍 Search support inside the editor (ctrl+f)
* 💡 Custom autocomplete suggestions
* 📄 Create new HTML files directly from the interface
* 📦 Export projects as ZIP archives
* 💾 Export entire projects back to a folder
* 📄 Export individual files
* 🖱️ Drag-and-drop file importing
* 🖥️ Fullscreen preview mode (ctrl+x to enter/exit or only esc to exit)
* 🔗 Internal project navigation support

## How It Works

1. Import a folder containing your HTML project or select individual files.
2. Browse the project structure using the sidebar.
3. Open any file for editing.
4. See changes instantly in the live preview panel.
5. Export your work as a file, folder, or ZIP archive.

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* CodeMirror
* JSZip

## Browser Compatibility

Advanced HTML Viewer works in modern browsers that support:

* File API
* File System Access API
* Blob URLs
* ES6+

For the best experience, use the latest version of Chromium-based browsers.
